ESP8266 REPORT SYSTEM - Android app v1.0

Функции:
- IP адрес, запомня се в телефона
- Свързване към ESP8266
- SSID и WiFi парола
- Запис на WiFi настройките
- Gmail App Password
- Тестов email
- Статус send ok / fall

ВАЖНО:
Тази първа версия използва HTTP към съществуващите маршрути на ESP8266.
Текущият ESP8266 код трябва да поддържа POST за /save, /saveemail и /testemail.
Ако искаме приложението да бъде напълно самостоятелно с полета, без да зависи от HTML страницата,
следващата версия трябва да добави GET/JSON API или да промени методите на тези маршрути.
